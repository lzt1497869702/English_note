除了指定内容，总是用中文交流。这个项目是一个基于MD格式记录的用于中国大学生考研的英语笔记，你需要创建或修改一些包含单词的表格，要求如下：

## 1.所有表格通用的规则

+ 表格只有表头加粗，其他内容不用加粗。
+ 表格中第一列的单词在每一行只出现一次，不能有两行及以上的第一列单词相同。
+ 每次添加或修改表格内容时，都要将单词按照日常生活的使用频率高低从上往下排序，频率高的排最上面，若表格第三列为“区别”一列，则还要检查并改善优化该列内容，让内容更详细准确。

## 2.表格设计、修改、整理可选规则：

### 2.1 规则1

该规则用于创建单词不同但中文释义相同或基本相同的表格。

+ 第一列：
  + 表头文本：单词
  + 内容要求：包括单词和音标，单词和音标使用`<br/>`连接，音标使用`包裹，这列单词按照使用频率高低从上往下排序，频率高的排最上面。
+ 第二列：
  + 表头文本：释义
  + 内容要求：包括词性和常见的中文释义，词性在前，并采用斜体，名词词性用`cn.`或`un.`表示；常见的中文释义在后，中文释义选择最常用的几个，满足考研、四六级的要求即可，若一个单词有多个词性及对应的中文释义，词性和中文释义为一组，每组在单元格内使用`<br/>`连接）。
+ 第三列：
  + 表头文本：区别
  + 内容要求：对这一行开头的单词用一段话详细清晰的说明该词的区别和使用场景。

### 2.2 规则2

+ 第一列与规则1第一列相同。
+ 第二列与规则1第二列相同。
+ 第三列：
  + 表头文本：举例
  + 内容要求：要求对这一行开头的单词举例一条英文示例句子和一条中文翻译，句子和翻译用`<br/>`连接，要求示例句子有一定的英语语法水平，不能过于简单）。 

### 2.3 规则3

该规则用于创建内容为英语短语的表格

+ 第一列：
  + 表头文本：短语
  + 内容要求：包括短语和音标，单词和音标使用`<br/>`连接，音标使用`包裹，这列单词按照使用频率高低从上往下排序，频率高的排最上面。
+ 第二列：
  + 表头文本：释义
  + 内容要求：包括词性和常见的中文释义，词性在前，并采用斜体，名词词性用`cn.`或`un.`表示；常见的中文释义在后，中文释义选择最常用的几个，满足考研、四六级的要求即可，若一个单词有多个词性及对应的中文释义，词性和中文释义为一组，每组在单元格内使用`<br/>`连接）。
+ 第三列与规则2第三列相同。
